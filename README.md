# Evra: Your Event Hub

Build a mobile-first web app called Evra for saving events. For now, focus only on the UI and navigation. Do not add authentication, backend, database or AI yet.

The visual style should be light, clean, modern and minimal, inspired by the simplicity of Luma.

Home screen:

 Evra wordmark

 Large “Drop an event here” upload area

 “Upload screenshot” button

 Drag-and-drop support on desktop

 Secondary “Add manually” action

 “Coming up” preview showing 2–3 mock events

 “View all events”

Events page:

 Upcoming events grouped chronologically by month

 Past Events section

 Simple event cards showing date, event name, time and location

Event detail page:

 Event name

 date/time

 location

 ticket release

 registration deadline

 notes

 original screenshot

 edit/delete actions

Make it responsive and prioritise mobile.
